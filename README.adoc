== 📖 Mission Statement
Created by *Rehman Ali*, the **FFmpeg-Tiny-Merger** is not just a repository; it is a precision-engineered build system. It produces ultra-stripped, high-performance `.so` binaries for Android, specifically optimized for **16KB page-size alignment** (mandatory for Android 15+).

== 🛠️ Feature Control Center (Customization)
The build is modular. You can "Toggle" features ON or OFF by modifying the `build.yml` file. Here is how you can craft your own custom build:

=== How to Customize:
1. **Fork** this repository to your account.
2. Edit the `.github/workflows/build.yml` file.
3. Locate the `./configure` section and toggle flags.

=== 🎛️ The Toggle Reference
[cols="1,1,2", options="header", frame=none, grid=rows]
|===
| Feature | Flag | Effect
| *Minimize Size* | `--disable-everything` | *DEFAULT:* Disables all features for the smallest footprint.
| *Add Video Support* | `--enable-decoder=h264` | Enables H.264 video decoding.
| *Add Audio Support* | `--enable-decoder=aac` | Enables AAC audio decoding.
| *Enable Merging* | `--enable-muxer=mp4` | Allows merging streams into an MP4 container.
| *Network Support* | `--enable-network` | *OFF by default.* Enable if you need to stream from URLs.
| *Advanced Scaling* | `--enable-swscale` | *ON by default.* Essential for video resizing.
|===

[IMPORTANT]
====
If you need a specific codec (like `mpeg4`), just add `--enable-decoder=mpeg4` to the configure list. If you want to remove something, simply delete its `--enable-` line.
====

== 🏗 Engineering Specs
[horizontal]
*Toolchain* :: LLVM / NDK r25c Integration
*Alignment* :: `-z max-page-size=16384` (Future-proof for Android 15)
*Optimization* :: `--enable-small` + `llvm-strip` (Production Ready)
*Binary Output* :: `libavcodec`, `libavformat`, `libavutil`, `libswresample`, `libswscale`.

== 🚀 Automation Pipeline
. **Trigger:** Push changes or manually run the workflow from the **Actions** tab.
. **Processing:** GitHub Actions compiles the source on Ubuntu-latest using a cloud-hosted NDK environment.
. **Artifacts:** Once complete, download the `Tiny-FFmpeg-8.1-arm64` bundle from the summary page.
